## Convenciones de wireframes

- Los wireframes de baja fidelidad (boceto) se crean primero para validar flujos.
- Los mockups de alta fidelidad siguen el sistema de diseño definido en `design-system.md`.
- Cada wireframe exportado debe estar en PNG (mínimo 1440px de ancho para desktop, 375px para mobile).
- El nombre del archivo sigue el formato `W-{NNN}-{nombre-descriptivo}.png`.
